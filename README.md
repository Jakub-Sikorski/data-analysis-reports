# Data Analysis & Machine Learning Portfolio

Welcome to my data analysis portfolio! This repository contains a curated collection of projects demonstrating my skills in exploratory data analysis, machine learning, mathematical statistics, and differential equations. The projects are implemented in both **Python** and **R**, covering real-world business scenarios as well as theoretical statistical simulations and mathematical modeling.

## Technologies & Skills
* **Python Ecosystem:** Pandas, NumPy, Scikit-learn, XGBoost, SHAP, Matplotlib, Seaborn, Skopt, UMAP.
* **R Ecosystem:** R Markdown, Base R Graphics, Statistical Inference, Monte Carlo Simulations.
* **Machine Learning:** Supervised Learning (Classification), Unsupervised Learning (Clustering, Dimensionality Reduction), Hyperparameter Tuning.
* **Mathematics & Statistics:** Hypothesis Testing, Point & Interval Estimation, Law of Large Numbers, Central Limit Theorem, Outlier Handling, Differential Equations.

---

## Project Overview

### Part I: Python (Machine Learning & Business Analytics)
1. **Analysis of the Polish Banking Sector Structure (2009–2025)**
   * **Focus:** EDA, data cleaning, and trend visualization.
   * **Summary:** Analysis of long-term structural changes, market consolidation, and digitalization impacts using official KNF (Polish Financial Supervision Authority) data.
2. **Bank Deposit Prediction using XGBoost**
   * **Focus:** Supervised Learning, Classification, Model Evaluation.
   * **Summary:** Building a predictive model to identify potential term deposit subscribers using telemarketing data. Includes Bayesian optimization and SHAP explainability.
3. **Credit Card Customer Segmentation**
   * **Focus:** Unsupervised Learning, Clustering, Dimensionality Reduction.
   * **Summary:** Segmenting credit card users based on financial behavior using K-Means, DBSCAN, PCA, and UMAP to assist in targeted marketing and risk management.

### Part II: R (Statistical Inference, Simulations & Modeling)
4. **Exploratory Data Analysis & Basic Statistics**
   * **Focus:** Central tendency, dispersion, robust statistics.
   * **Summary:** Analyzing student performance and US income distributions, highlighting the application of trimmed means for heavily right-skewed financial data.
5. **Statistical Theorems Simulation (LLN & CLT)**
   * **Focus:** Probability theory, distributions.
   * **Summary:** Simulating dice rolls, coin flips, and population sampling to visually and mathematically verify fundamental statistical theorems.
6. **Point Estimators Analysis**
   * **Focus:** Estimator bias, variance, MSE, robustness to anomalies.
   * **Summary:** Comparing the effectiveness of various estimators (e.g., mean vs. median) under different distributions and extreme outlier scenarios.
7. **Interval Estimation & Confidence Intervals**
   * **Focus:** Confidence intervals, Agresti-Coull method.
   * **Summary:** Evaluating coverage probabilities for means, variances, and proportions using Monte Carlo simulations.
8. **Hypothesis Testing & Medical Data Analysis**
   * **Focus:** P-value distributions, Type I errors, Welch's t-test.
   * **Summary:** Theoretical power simulations and practical application analyzing cholesterol levels in heart attack patients.
9. **Forensic Application of Newton's Law of Cooling**
   * **Focus:** Mathematical Modeling, Differential Equations, LaTeX.
   * **Summary:** Utilizing first-order differential equations to calculate the cooling constant of a human body and estimate the exact time of death based on crime scene temperature measurements.

## Repository Structure & Note on Data
Each project folder contains the source code (`.ipynb` or `.Rmd`) alongside rendered, easy-to-read reports (`.html` or `.pdf`). 

*Note: Due to file size limits and academic/licensing constraints, raw datasets (e.g., `.csv`, `.dat`, `.txt`) are intentionally excluded from this repository via `.gitignore`. The complete analysis, code logic, and visualizations are fully accessible within the report files.*
